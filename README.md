# claude-tail

[Claude Code](https://docs.claude.com/en/docs/claude-code) のセッションの会話を、別ターミナルで
`tail -f` のように追いかけて読みやすいテキストにする CLI ツール。

```
━━━ user 2026-01-01 09:00:00 ━━━
README を直して

━━━ assistant 2026-01-01 09:00:05 ━━━
直しました。変更点は次のとおりです。
...
```

応答やコマンドの長い出力をコピペしたいとき、ターミナルのスクロールバックから選ぶと折り返しや装飾が混ざる。
組み込みの `/copy` は直前の応答1件だけ、`/export` はその時点のスナップショットだけなので、
会話をログのように流し続けたり、ファイルに書き出し続けたりするために作った。

## 主な機能

- 今のディレクトリで開いた最新のセッションを、最初から表示して以降の発言を追いかける
- 画面に流しつつファイルにも書き出す(`-o`)
- ツールの呼び出しと結果(コマンドの生出力)も出せる(`-t`)
- セッションの一覧(タイトル付き)と、セッションID の前方一致での指定
- **読み取り専用。** Claude Code のトランスクリプトには一切書き込まない

## 動作環境

- Ruby 4.0.5 以上を推奨(それ未満での動作は保証しない)。標準ライブラリだけで動き、gem は不要
- macOS / Linux

## インストール

```bash
git clone https://github.com/huro3h/claude-tail.git
ln -s "$PWD/claude-tail/bin/claude-tail.rb" /usr/local/bin/claude-tail
```

リンク先は PATH の通ったディレクトリならどこでもよい(`/opt/homebrew/bin`、`~/bin` など)。
リンクなので、更新は `git pull` だけで済む。

## 使い方

```bash
claude-tail                         # 最新セッションを最初から表示し、以降の発言を追いかける
claude-tail -o session.txt          # 画面に流しつつファイルにも書き出す(上書き)
claude-tail -n                      # 既存分は飛ばし、これからの発言だけ
claude-tail -t                      # ツール呼び出しと結果(コマンドの生出力)も出す
claude-tail --no-follow > out.txt   # 今ある分を一括で書き出して終了
claude-tail -l                      # セッション一覧(更新が新しい順、タイトル付き)
claude-tail 1a2b                    # セッションID の前方一致で指定
claude-tail -C ~/dev/app            # 別ディレクトリで開いたセッションを対象にする
claude-tail path/to/xxx.jsonl       # ファイルを直接指定
```

Ctrl-C で終了する(終了コード 0)。エラーは終了コード 2。

選んだセッションの ID とタイトルは標準エラーに出る。同じディレクトリで複数のセッションを並行して開いていると
「最新」が意図したものと違うことがあるため、別のセッションも直近10分以内に更新されていれば警告を出す。
そのときは `claude-tail -l` で確かめて ID を指定する。

### 毎回ファイルにも残す

環境変数 `CLAUDE_TAIL_LOG_DIR` を設定しておくと、`-o` を付けなくても、そのディレクトリへセッションごとのファイルに
書き出す(ディレクトリが無ければ作る)。

```bash
# ~/.zshrc など
export CLAUDE_TAIL_LOG_DIR="$HOME/Documents/claudecode-logs"
```

- ファイル名は `<セッションの開始日>_<タイトル>_<セッションIDの先頭8文字>.txt`(例: `2026-01-01_READMEの修正_1a2b3c4d.txt`)。
- 同じセッションを tail し直すと、同じファイルを最初から書き直す。タイトルが変わっていたら、ファイル名も今のタイトルに付け替える。
- `-n` のときは前回までの記録を消さないよう、既存のファイルに追記する。
- `-o` を指定したときはそちらだけに書き出す。その回だけ書き出したくないときは `--no-save`。

### 出力の形

~~~
━━━ user 2026-01-01 09:00:00 ━━━
(発言)

━━━ assistant 2026-01-01 09:00:05 ━━━
(応答の本文)

━━━ tool 2026-01-01 09:00:09 ━━━      ← -t の時だけ
◀ result
```
(ツールの出力)
```
~~~

- 時刻はローカル時刻。
- 思考(thinking)、スキル本文などの注入、サブエージェントの会話は出さない。
- 見出しを Markdown の `##` にしていないのは、応答の本文自体に `##` 見出しが入っていて区別がつかなくなるため。

## 仕組みと注意

Claude Code は会話を1行1イベントの JSONL として、次の場所にリアルタイムに書き出している。

```
~/.claude/projects/<プロジェクト名>/<セッションID>.jsonl
```

`<プロジェクト名>` は作業ディレクトリの絶対パスの英数字以外を `-` にしたもの。
環境変数 `CLAUDE_CONFIG_DIR` で設定ディレクトリを移している場合は、`~/.claude` の代わりにそちらを読む。

このファイルの形式は Claude Code の**内部仕様で、公開ドキュメントはない**。claude-tail の解釈は実物を
観察した結果なので、Claude Code の更新で表示されなくなる可能性がある。

## 開発

```bash
ruby test/claude_tail_test.rb
```

テストは `CLAUDE_CONFIG_DIR` を一時ディレクトリに向けて動かすので、手元の `~/.claude` には触れない。
